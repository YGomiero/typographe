# Typographe 2.0.7 · Joomla 6

**Français** — Correction typographique pendant l’édition, avec aperçu HTML et choix des corrections par clic. Aucun traitement typographique lors de l’affichage public.

**English** — Typography correction while editing, with an HTML preview and clickable individual changes. No display-time typography processing on public pages.

- [Documentation française](docs/README.fr.md)
- [English documentation](docs/README.en.md)
- [Changes / Historique](changelog.txt)
- [Download the installable ZIP / Télécharger le ZIP installable](https://github.com/YGomiero/typographe/releases/tag/2.0.7)

Requires **Joomla 6, PHP 8.3+, DOM and mbstring**. The ZIP contains its dependencies; Composer is not needed on the Joomla server. Tested locally with Joomla 6.2.0 / PHP 8.3.30.

Powered by [JoliTypo](https://github.com/jolicode/JoliTypo) **1.8.0**, with Hyphenator 3.2.0 and Symfony Intl Normalizer polyfill 1.43.0. Versions are pinned in `composer.lock`. This release targets PHP 8.3 and does not track JoliTypo's development branch.

## Development / Développement

```sh
composer install --no-dev --prefer-dist --optimize-autoloader
php tests/run.php
node tests/compare.cjs
php tests/joomla.php /absolute/path/to/joomla
php tools/build.php /absolute/path/to/plg_system_typographe-2.0.7.zip
```

Run the integration tests against a local Joomla 6 installation. They use Joomla classes with an isolated test application and do not save site content. PHP ZipArchive is required to build the package. `dependencies/` is generated by Composer and included in the installable ZIP, not tracked in Git. GitHub's automatically generated source archives are **not** installable Joomla packages.

## Publishing updates / Publier une mise à jour

1. Update the manifest version and documentation / Mettre à jour la version du manifeste et la documentation.
2. Build `plg_system_typographe-X.Y.Z.zip` with `php tools/build.php` and attach it to a draft GitHub release with the numeric tag `X.Y.Z` / Construire le ZIP et le joindre à une version brouillon portant le tag numérique correspondant.
3. Publish a stable release and mark the newest supported version as Latest / Publier une version stable et désigner la plus récente compatible comme Latest.
4. The `Joomla update feed` workflow downloads the attached ZIP, checks its version, generates `update.xml` with its SHA-256 and uploads it to that release / Le workflow valide le ZIP joint et publie son flux XML avec empreinte SHA-256.
5. Verify that the workflow succeeds before announcing the update. If it fails, fix the missing/incorrect ZIP and rerun the failed workflow / Vérifier le succès ; en cas d’échec, corriger le ZIP et relancer le workflow.

Stable feed / Flux stable: `https://github.com/YGomiero/typographe/releases/latest/download/update.xml`

Drafts and prereleases are excluded. Each XML feed points to a versioned ZIP, targets Joomla 6 and PHP 8.3+, and is generated from the exact attached package. Keep the previous stable release as Latest until the next release's feed is ready. No automatic unattended installation or public-page updater is added to Joomla.

Les brouillons et préversions sont exclus. Le flux pointe vers un ZIP versionné, cible Joomla 6/PHP 8.3+ et utilise le fichier réellement joint. Conserver la précédente version stable comme Latest jusqu’à disponibilité du flux suivant. Aucun installateur sans intervention ni traitement à l’affichage public n’est ajouté.

Manual fallback / Secours manuel:
```sh
python tools/update-feed.py plg_system_typographe-X.Y.Z.zip X.Y.Z update.xml
```
Attach the generated `update.xml` to the same release / Joindre le XML généré à cette même version.
